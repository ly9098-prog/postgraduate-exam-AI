# Coding Rules — 导入管线系统

> 状态：早期导入管线 Prompt，不是当前最高规则。以根目录 `AGENTS.md`、`docs/project/PROJECT_RULES.md` 和代码为准。下文里的模型、JWT 天数和目录树可能已过时。

## 代码风格

- Python 3.11+，类型注解全覆盖（函数参数和返回值必须有类型标注）
- 使用 `ruff` 做 lint + format（配置见 `pyproject.toml`）
- 一个文件不超过 300 行，一个函数不超过 50 行
- 不写接口/抽象类，不写装饰器以外的 AOP
- 不写 `__repr__`、不写自定义 Query

## 禁止硬编码

- 题型映射表、学科映射表、正则模式串必须放在模块顶层的常/变量中
- 不允许在函数内部写死字符串匹配模式
- Prompt 模板统一放在 `app/ai/prompts.py`，不散落在业务代码中
- 所有配置项（token 限额、超时时间、API 端点）走 `app/core/config.py`

## 可测试性

- 核心函数必须是纯函数（输入 → 输出，无副作用）或副作用在边界隔离
- 文件 I/O、API 调用必须可 mock / 可注入
- 每个阶段的核心函数必须可单文件调用测试

## 模块化

- 一个阶段一个核心文件，不跨模块引用内部符号
- 模块间只通过函数调用和返回值通信，不共享全局状态
- 同阶段内工具函数可放同文件底部或 `_helper` 前缀函数

## Prompt 不允许写死

- Prompt 模板中不嵌入业务数据
- 题型列表、学科列表从配置/常量读取，动态拼入 prompt
- 所有 AI 调用走 `app/ai/client.py`，不直接在业务代码中构造 http 请求

## AI 逻辑可开关

- AI 修复模块必须有一个全局开关（配置项），关闭后不调用 API
- AI 模块的 import 必须是延迟/条件 import，不影响核心管线启动
- AI 不可用时必须静默降级，不抛异常阻塞流程
