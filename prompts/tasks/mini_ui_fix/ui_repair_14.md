请优化小程序 `pages/wrong-detail` 页面中的“AI解题技巧”区域，使其更符合考研刷题用户的错题复盘需求。

一、问题背景
当前页面展示的三个模块为“解题思路”“核心考点”“快速方法”。这三个模块虽然有一定帮助，但容易与题目原有解析重复，且没有充分利用错题详情页中的“我的答案”“正确答案”“题目解析”等上下文信息。对于考研群体来说，错题页更重要的价值不是再次讲一遍解法，而是帮助用户明确为什么错、需要补什么、接下来如何复练。

二、优化目标
将当前“AI解题技巧”区域升级为“AI错题复盘”，把原来的三个模块替换为：

1. 错因诊断
   用于分析用户为什么做错。需要结合题干、选项、正确答案、用户答案和题目解析，判断用户的错误类型，例如概念混淆、公式误用、条件漏看、审题偏差、计算失误、选项干扰、步骤缺失等。内容要具体指出关键失分点和题目陷阱，避免泛泛而谈。
2. 补漏重点
   用于指出这道错题暴露出的薄弱知识点。不能只是列出“核心考点”，而要说明该考点需要补什么，包括定义、公式、适用条件、易混点、常见命题方式等。不同学科要适配不同表达方式：数学侧重公式、条件和步骤；英语侧重词汇、语法、句子结构和选项干扰；政治侧重概念辨析、关键词和材料逻辑；专业课侧重概念、原理、模型、步骤或典型考法。
3. 复练任务
   用于告诉用户下一步如何练习。内容应给出可执行动作，例如是否当天重做、建议补做几道同类题、1天/3天/7天后是否复刷、下一次遇到类似题先检查什么、是否建议进入专项练习或生成同类题。避免空泛的“多练习、回顾知识点”等无效建议。

三、前端修改要求
修改 `miniprogram/pages/wrong-detail/wrong-detail.wxml` 中 AI 区域文案：

- 标题由“AI 解题技巧”改为“AI 错题复盘”
- 副标题改为“定位错因、补齐考点、安排下一次复练”
- 未生成状态说明改为“点击后将生成错因诊断、补漏重点和复练任务。”
- 按钮文案由“生成 AI 解题技巧”改为“生成 AI 错题复盘”
- 成功状态中的三个标签改为：
  - 错因诊断
  - 补漏重点
  - 复练任务

四、前端字段适配
新版 AI 返回字段建议为：

```json
{
  "mistake_diagnosis": "错因诊断内容",
  "knowledge_patch": "补漏重点内容",
  "review_task": "复练任务内容"
}
```

前端展示时应优先使用新版字段，并兼容旧字段：

```js
mistake_diagnosis = aiResult.mistake_diagnosis || aiResult.error_analysis
knowledge_patch = aiResult.knowledge_patch || aiResult.knowledge_weakness
review_task = aiResult.review_task || aiResult.suggestion
```

如果使用计算字段或数据预处理，避免直接在 WXML 中写复杂表达式，保证页面可维护性。

五、后端 Prompt 修改要求
修改 `app/ai/prompts.py` 中 `SYSTEM_PROMPTS["error_analysis"]` 以及 `build_error_analysis` 的用户提示词。

新的系统提示词应强调：
你是考研错题复盘教练，不只是讲解题目，而是要结合用户答案和正确答案定位错因、提炼补漏重点、给出复练任务。输出要具体、简洁、可执行，不要重复题目原解析，不要输出空泛建议。

输出格式必须为严格 JSON：

```json
{
  "mistake_diagnosis": "指出用户为什么错，包括错误类型、关键失分点和题目陷阱，最多120字",
  "knowledge_patch": "指出本题暴露的薄弱考点、必补公式/定义/规则、适用条件或易混点，最多120字",
  "review_task": "给出下一步复练动作，包括重做、同类题、复刷间隔或下次检查点，最多120字"
}
```

六、缓存兼容要求
当前 `WrongQuestion.ai_analysis` 可能已经缓存旧字段 `error_analysis / knowledge_weakness / suggestion`。需要处理以下情况：

1. 如果命中旧缓存，前端可以临时兼容展示；
2. 点击“重新生成”时，应生成新版字段；
3. 如果后端已有缓存判断逻辑，建议增加旧结构识别：当缓存中不存在 `mistake_diagnosis / knowledge_patch / review_task` 时，可视为旧缓存，允许重新生成或返回时做字段转换；
4. 不要让旧内容长期挂在新标题下，避免“快速方法”内容被展示成“复练任务”导致语义不一致。

七、降级文案修改
如果 AI 不可用，原文“AI 解题技巧暂时不可用”建议改为：

“AI 错题复盘暂时不可用”

降级说明建议改为：

“建议先查看题目解析并手动标记错因，稍后再试。”

八、验收标准

1. 页面不再出现“解题思路”“核心考点”“快速方法”三个旧标签。
2. 页面显示为“AI 错题复盘”，并展示“错因诊断”“补漏重点”“复练任务”。
3. 后端 AI 返回新版 JSON 字段：`mistake_diagnosis`、`knowledge_patch`、`review_task`。
4. 旧缓存数据不会导致页面报错。
5. AI 输出内容必须围绕“为什么错、补什么、怎么练”，不能只是重复题目解析。
6. 每个模块内容控制在 120 字以内，适合小程序移动端阅读。
7. 重新生成按钮可正常触发新版 AI 结果。
8. 数学、英语、政治、专业课等不同题型下，输出内容要符合学科特点。
