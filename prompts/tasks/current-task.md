        ## 408 科目拆分
        -----------------------------------
      
        将 408 拆分为：
      
        - DS（数据结构）
        - OS（操作系统）
        - CO（计算机组成原理）
        - CN（计算机网络）
      
        要求：
      
        1. UI中优先显示缩写：
        - DS
        - OS
        - CO
        - CN
      
        2. 长按/tooltip/详情页可显示全称。
      
        3. 后端数据结构支持：
        - parentSubject
        - subSubject
        - code
        - displayName
      
        示例：
      
        {
        parentSubject: "408",
        subSubject: "DS",
        displayName: "数据结构"
        }
      
        4. 题目导入流程支持：
        AI/OCR解析后自动归类：
      
        例如：
        - 链表
        - 栈
        - 红黑树
        → DS
      
        - 进程
        - 死锁
        - 调度
        → OS
      
        - Cache
        - 指令系统
        → CO
      
        - TCP/IP
        - HTTP
        - 路由
        → CN
      
        5. 刷题统计支持：
        - 总408统计
        - 子科目统计
        - DS正确率
        - OS错题率
        - CO掌握度
        - CN刷题量
