# 功能目标

基于当前已经完成的 OCR 导题功能，实现「多图片批量导题」能力。

注意：

- 当前单图片 OCR → AI解析 → 题目录入流程已经稳定运行
- OCR识别精度已满足需求
- 本次任务不允许重构 OCR 核心逻辑
- 不允许修改 PaddleOCR 配置
- 不允许更换 OCR 模型
- 重点是提升导题效率，而不是提升识别率

------

# 当前流程

现有流程：

```text
上传单张图片
↓
PaddleOCR识别
↓
OCR文本
↓
AI题目结构化
↓
生成待审核题目
```

能够正常工作。

------

# 需要实现的新流程

新增：

```text
批量上传图片（10~100张）
↓
系统自动逐张执行现有OCR流程
↓
自动汇总所有识别结果
↓
统一进入待审核题库
```

即：

```text
图片1
图片2
图片3
...
图片N

↓
自动处理

↓

待审核题目列表
```

无需用户逐张上传。

------


------

# 任务队列

批量任务必须采用队列模式。

例如：

```text
任务总数：56

已完成：23

处理中：1

等待中：32
```

避免：

```text
56张图片同时OCR
```

导致：

- 内存爆炸
- CPU占满
- AI接口限流

建议：

```text
并发2~4个任务
```

其余排队。

# 错误处理

如果单张图片失败：

```text
图片17失败
```

记录日志。

继续执行：

```text
图片18
图片19
图片20
```

不能因为一张失败终止整个任务。

------

# OCR文本缓存

新增：

```text
ocr_raw_text
```

字段。

保存：

```text
OCR原始文本
```

后续：

- AI解析失败
- Prompt调整
- 重新解析

无需再次OCR。

直接使用缓存文本。
