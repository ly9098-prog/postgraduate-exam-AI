# 王道408题库导入能力升级（二阶段）

## 项目目标

当前系统已经具备基础 OCR 能力，但对于王道408扫描版PDF仍存在以下问题：

- 无法准确区分教材正文与题目内容
- 无法稳定识别单选题、多选题、判断题
- 无法准确提取题目选项
- 无法自动关联答案与解析
- 水印、页码、章节标题会干扰识别结果
- 题目导入后仍需要大量人工整理

目标是将 OCR 能力升级为「题库级解析能力」，实现从扫描PDF自动生成标准题库数据。

------

## 第二阶段处理流程

### 1. OCR识别

输入：

- PDF页面图片

输出：

- 原始文本
- 文本坐标
- OCR置信度

要求：

- 支持扫描PDF
- 支持低质量图片
- 支持王道水印干扰场景

------

### 2. 版面分析（Layout Analysis）

目标：

识别页面结构。

需要区分：

- 章节标题
- 正文内容
- 例题区域
- 选择题区域
- 判断题区域
- 图片区域
- 表格区域
- 页眉页脚
- 页码
- 水印

输出：

页面结构树。

------

### 3. 题目检测（Question Detection）

目标：

从版面结构中提取题目。

支持识别：

- 单选题
- 多选题
- 判断题

识别内容：

- 题号
- 题干
- 题目所在章节

示例：

1. 下列关于进程的说法正确的是（）

------

### 4. 选项检测（Option Detection）

目标：

自动识别选项。

支持：

A.
B.
C.
D.

以及：

A、
B、
C、
D、

输出：

[
"A.xxx",
"B.xxx",
"C.xxx",
"D.xxx"
]

------

### 5. 答案检测（Answer Detection）

目标：

识别答案区域。

支持：

答案：A

正确答案：A

【答案】A

参考答案：A

判断题：

√
×

正确
错误

输出：

answer

------

### 6. 知识点过滤（Content Filtering）

目标：

过滤非题目内容。

需要过滤：

- 王道品牌水印
- 页码
- 页眉
- 页脚
- 教材正文
- 章节介绍
- 非题目示例

保留：

- 题目
- 选项
- 答案
- 解析

------

### 7. 结构化输出（Structured Output）

统一输出格式：

{
"type": "single_choice",
"question": "",
"options": [],
"answer": "",
"analysis": "",
"chapter": "",
"source": "王道408"
}

## 各模块职责

### pdf2image

职责：

- PDF转图片
- 页面切分
- 图片预处理

------

### PaddleOCR

职责：

- 文本识别
- 坐标提取
- OCR置信度输出

------

### PP-Structure

职责：

- 页面版面分析
- 区块识别
- 页面结构理解

输出：

结构化页面布局信息

------

### Question Parser

职责：

根据版面结构识别：

- 单选题
- 多选题
- 判断题

提取：

- 题号
- 题干
- 选项
- 答案
- 解析

------

### Rule Correction Layer

职责：

OCR纠错与规则修复。

示例：

1O24 → 1024

Cachc → Cache

自动补全缺失选项。

统一题目格式。
