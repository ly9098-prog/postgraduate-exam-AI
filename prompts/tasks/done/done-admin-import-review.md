# 任务目标

将当前题目导入体系调整为：

```text
Admin后台
    ↓
主要导入入口

微信小程序
    ↓
轻量导入入口
```

未来所有大规模题目导入优先在 Admin 后台完成。

------

# 整体架构要求

保留现有导入服务层（OCR、解析、题目拆分等）。

避免复制业务逻辑。

统一使用：

```text
ImportService
QuestionImportService
OCRService
```

后台和小程序共用同一套导入流程。

仅界面和权限不同。

------

```text

```

# 技术要求

1. 不复制现有导入逻辑。
2. 提取公共 Import Service。
3. Admin 与小程序共用导入核心代码。
4. 保持现有数据库兼容。
5. 尽量减少数据库结构变更。
6. 优先复用现有 OCR 流程。
