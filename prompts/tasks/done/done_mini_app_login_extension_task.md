- 【登录态持久化优化任务】

  基于当前小程序登录架构，全面排查并修复登录态频繁失效问题。当前现象为：用户将小程序切入后台、后台被系统清理或重新进入小程序后，经常需要重新登录。

  目标：

  实现“一次登录、长期使用”的登录体验，在用户未主动退出登录的情况下，尽可能保持登录状态持续有效。

  优化要求：

  1. 排查当前登录态丢失的根本原因（Token 存储、Token 过期策略、Session 校验、自动续签机制等）。
  2. 优化 Token 生命周期管理，建立安全可靠的自动续签机制。
  3. 完善小程序启动（App Launch）、显示（App Show）及接口请求阶段的登录态恢复逻辑。
  4. 避免因后台清理、应用重启、网络波动等场景导致用户被迫重新登录。
  5. 仅在以下场景要求重新登录：
     - 用户主动退出登录；
     - Refresh Token 已失效；
     - 服务端明确判定账号状态异常；
     - 登录凭证被撤销。
  6. 输出完整的问题分析、修复方案、代码改动说明及验证结果。

  验收标准：

  - 小程序后台被系统清理后重新打开，仍保持登录状态。
  - 小程序关闭后重新进入，仍保持登录状态。
  - Token 即将过期时自动完成续签。
  - 连续使用数周无需重复登录。
  - 不降低现有账号安全性。
