## 四、需要补充的 P0 公式卡

以下内容属于高优先级。若数据库已有完整且准确的卡片，不要重复新增；应补全、纠错、关联知识点，并按照现有审核流程处理。

### 1. 弧微分与参数方程弧长

建议标题：

- `弧微分与曲线弧长`
- 或按照项目已有命名规范调整

必须包含：

```latex
ds=\sqrt{1+[y'(x)]^2}\,dx
```

参数方程：

```latex
ds=\sqrt{[x'(t)]^2+[y'(t)]^2}\,dt
s=\int_{\alpha}^{\beta}
\sqrt{[x'(t)]^2+[y'(t)]^2}\,dt
```

说明适用条件和积分上下限方向。

### 2. 曲率与曲率半径

必须包含：

```latex
\kappa=\frac{|y''|}{[1+(y')^2]^{3/2}}
\rho=\frac{1}{\kappa}
```

参数方程形式：

```latex
\kappa=
\frac{|x'y''-y'x''|}
{[(x')^2+(y')^2]^{3/2}}
```

说明：

- `\kappa` 是曲率；
- `\rho` 是曲率半径；
- 需要注意参数曲线导数均对参数求导。

### 3. 曲率圆圆心

必须包含：

```latex
x_c=x-\frac{y'[1+(y')^2]}{y''}
y_c=y+\frac{1+(y')^2}{y''}
```

同时说明适用条件：

```latex
y''\ne 0
```

并说明曲率圆半径为 `\rho`。

### 4. 旋转曲面侧面积

必须包含统一形式：

```latex
S=2\pi\int r\,ds
```

绕 `x` 轴：

```latex
S_x=2\pi\int_a^b |y|
\sqrt{1+(y')^2}\,dx
```

绕 `y` 轴：

```latex
S_y=2\pi\int_a^b |x|
\sqrt{1+(y')^2}\,dx
```

需要明确：

- `r` 是曲线上一点到旋转轴的距离；
- 半径可能需要绝对值；
- 不要与旋转体体积公式混淆。

### 5. 定积分的功与液体压力

建议拆为一张综合模板卡，或按照当前卡片粒度拆开。

功：

```latex
W=\int_a^b F(x)\,dx
```

液体静压力通用建模形式：

```latex
F=\rho g\int h(y)w(y)\,dy
```

必须解释：

- `h(y)` 表示深度；
- `w(y)` 表示该高度处薄条宽度；
- 实际上下限由几何区域确定；
- 单位需要统一。

### 6. 平面图形的质心与形心

一般区域 `D`：

```latex
\bar{x}=
\frac{\iint_D x\,dA}{\iint_D dA}
\bar{y}=
\frac{\iint_D y\,dA}{\iint_D dA}
```

对区域：

```latex
0\le y\le f(x),\quad a\le x\le b
```

包含：

```latex
A=\int_a^b f(x)\,dx
\bar{x}=\frac{1}{A}\int_a^b xf(x)\,dx
\bar{y}=\frac{1}{2A}\int_a^b [f(x)]^2\,dx
```

### 7. 一阶齐次微分方程

必须包含标准形式：

```latex
y'=F\left(\frac{y}{x}\right)
```

代换：

```latex
v=\frac{y}{x},\qquad y=vx
y'=v+xv'
```

说明代换后通常化为可分离变量方程。

不要将“一阶齐次微分方程”误写成“一阶线性齐次微分方程”。

### 8. 微分方程基本概念与解的结构

覆盖：

- 阶；
- 解；
- 通解；
- 特解；
- 初始条件；
- 初值问题；
- 齐次线性方程解的线性组合；
- 非齐次线性方程通解结构。

必须包含：

```latex
y=y_h+y_p
```

其中：

- `y_h` 是对应齐次方程通解；
- `y_p` 是非齐次方程的一个特解。

### 9. 高阶常系数齐次线性微分方程

一般特征方程：

```latex
a_nr^n+a_{n-1}r^{n-1}+\cdots+a_1r+a_0=0
```

实重根 `r`，重数为 `m`：

```latex
e^{rx},\ xe^{rx},\ \ldots,\ x^{m-1}e^{rx}
```

复根：

```latex
\alpha\pm i\beta
```

对应：

```latex
e^{\alpha x}
\left(C_1\cos\beta x+C_2\sin\beta x\right)
```

复根重数为 `m` 时，应说明还需要依次乘：

```latex
1,x,\ldots,x^{m-1}
```

### 10. 正交矩阵

必须包含：

```latex
Q^TQ=QQ^T=E
Q^{-1}=Q^T
|\det Q|=1
```

并说明：

- 正交矩阵的行向量和列向量均构成标准正交组；
- 正交变换保持向量长度和内积。

### 11. 施密特正交化

必须包含：

```latex
\beta_1=\alpha_1
\beta_k=
\alpha_k-
\sum_{j=1}^{k-1}
\frac{(\alpha_k,\beta_j)}
{(\beta_j,\beta_j)}\beta_j
```

单位化：

```latex
e_k=\frac{\beta_k}{\|\beta_k\|}
```

说明输入向量组应线性无关。

### 12. 克拉默法则

对线性方程组：

```latex
Ax=b
```

当：

```latex
D=\det A\ne 0
```

时：

```latex
x_i=\frac{D_i}{D}
```

说明：

- `D_i` 是用常数列替换系数矩阵第 `i` 列后得到的行列式；
- 主要适合理论判断和低阶计算。

### 13. 初等矩阵与矩阵等价

必须覆盖：

- 初等行变换对应左乘初等矩阵；
- 初等列变换对应右乘初等矩阵；
- 初等矩阵可逆；
- 初等矩阵的逆仍是初等矩阵。

矩阵等价：

```latex
A\sim B
\iff
B=PAQ
```

其中 `P,Q` 为可逆矩阵。

### 14. 分块矩阵常用公式

至少覆盖：

- 分块矩阵乘法；
- 分块转置；
- 分块对角矩阵；
- 分块三角矩阵的行列式；
- 可逆分块三角矩阵的逆。

公式：

```latex
\begin{pmatrix}
A&B\\
0&D
\end{pmatrix}^{-1}
=
\begin{pmatrix}
A^{-1}&-A^{-1}BD^{-1}\\
0&D^{-1}
\end{pmatrix}
```

前提是 `A,D` 均可逆。

### 15. 合同变换与二次型

必须包含：

```latex
B=C^TAC
```

其中 `C` 可逆。

说明合同变换保持：

```latex
r(A)=r(B)
p(A)=p(B),\qquad q(A)=q(B)
```

其中 `p,q` 分别为正惯性指数和负惯性指数。

另增加一张简洁辨析卡，区分：

- 矩阵等价；
- 矩阵相似；
- 矩阵合同。

## 五、需要补充的 P1 高频公式卡

这些属于真题高频结论。已有卡片不完整时进行补全。

### 1. 伴随矩阵的秩

对 `n` 阶矩阵 `A`：

```latex
r(A^*)=
\begin{cases}
n,&r(A)=n,\\
1,&r(A)=n-1,\\
0,&r(A)\le n-2.
\end{cases}
```

同时包含：

```latex
AA^*=A^*A=(\det A)E
\det(A^*)=(\det A)^{n-1}
```

当 `A` 可逆：

```latex
A^*=(\det A)A^{-1}
```

### 2. 秩与线性方程组解的关系

对：

```latex
Ax=b
```

必须形成一张清晰的判断表：

- `r(A)<r(A|b)`：无解；
- `r(A)=r(A|b)=n`：唯一解；
- `r(A)=r(A|b)<n`：无穷多解；
- 齐次方程组有非零解当且仅当：

```latex
r(A)<n
```

### 3. 相似矩阵的常用不变量

若：

```latex
B=P^{-1}AP
```

则相同的量包括：

- 特征多项式；
- 特征值及代数重数；
- 行列式；
- 迹；
- 秩。

不要错误声称相似矩阵对应元素、特征向量或具体矩阵条目相同。

### 4. 可交换矩阵的常用结论

若：

```latex
AB=BA
```

说明：

- `B` 保持 `A` 的每个特征子空间；
- 若 `A` 有 `n` 个互不相同的特征值，则可在 `A` 的特征向量基下同时讨论 `B`；
- 不要写成“任意可交换矩阵必可同时对角化”；
- 必须明确同时对角化还需要相应的可对角化条件。

### 5. 二重积分交换次序模板

不要只给一个机械公式，卡片中应包含步骤：

1. 画积分区域；
2. 从原积分识别区域；
3. 找新的投影区间；
4. 写新积分限；
5. 必要时分区。

常见形式：

```latex
\int_a^b dx\int_{\varphi_1(x)}^{\varphi_2(x)}
f(x,y)\,dy
```

交换后可能写为：

```latex
\int_c^d dy\int_{\psi_1(y)}^{\psi_2(y)}
f(x,y)\,dx
```

### 6. 指数衰减型函数的极值

对：

```latex
f(x)=x^\alpha e^{-\beta x},
\qquad x>0,\quad \alpha,\beta>0
```

包含：

```latex
\frac{f'(x)}{f(x)}
=
\frac{\alpha}{x}-\beta
```

极值点：

```latex
x=\frac{\alpha}{\beta}
```
