# 四、Word 原生数学公式 OMML

当前 LaTeX 公式以 PNG 图片嵌入可以保留作为降级，但本期需要增加原生公式路径。

## 4.1 渲染优先级

公式处理顺序：

1. 可识别公式转换为 MathML；
2. MathML 转换为 OMML；
3. 将 OMML 写入 DOCX；
4. OMML 转换失败时渲染高清透明 PNG；
5. PNG 渲染失败时显示原始公式文本。

不得因为 OMML 失败导致整份任务失败。

## 4.2 支持内容

至少验证：

- 行内公式；
- 块级公式；
- 分数；
- 根式；
- 上标；
- 下标；
- 求和；
- 积分；
- 矩阵；
- 括号；
- 希腊字母；
- 多行公式；
- 化学上下标；
- Unicode 数学符号。

## 4.3 行内公式

行内公式必须尽量保持在原段落中。

不能将全部公式强制独占一行。

## 4.4 公式安全

公式处理不能：

- 执行 shell；
- 执行任意 LaTeX 命令；
- 读取本地文件；
- 请求任意网络地址；
- 写入任务目录之外；
- 导致无限递归或超长解析。

增加：

- 输入长度限制；
- 解析超时；
- 嵌套深度限制；
- 缓存；
- 失败日志。

## 4.5 OMML 测试

通过解压 DOCX 检查：

- `word/document.xml` 中存在 `m:oMath` 或 `m:oMathPara`；
- 行内和块级公式位置正确；
- 失败公式使用图片或原始文本；
- 不存在题目内容丢失。

- `updated_at`
