## 3. LaTeX 规范

所有数学内容统一转为项目支持的规范 LaTeX。

重点检查：

- JSON 中反斜线转义；
- `\frac`；
- `\sqrt`；
- `\lim` 的趋向条件；
- `\int` 的上下限；
- `\sum`；
- `\prod`；
- 上标、下标；

- 高阶导数；
- 向量、矩阵和行列式；

- 括号层级；
- 绝对值和范数；
- 概率条件符号；
- 期望、方差和协方差；
- 排列组合符号。

中文条件建议使用：

```latex
n\text{ 为正偶数}
```

不要把中文直接放进数学命令参数中导致渲染失败。

## 4. 公式准确性验证

对于容易程序验证的公式，应进行符号或数值抽样验证。

例如：

- 导数公式可用 SymPy 对比；
- 积分公式可通过求导复核；
- 三角恒等式可数值抽样；
- 矩阵公式可用随机小矩阵验证；
- 概率分布应检查归一性和参数范围；
- 递推公式应检查若干小整数；
- 泰勒展开应检查展开阶数与余项形式。

验证失败时不得自动落库。
