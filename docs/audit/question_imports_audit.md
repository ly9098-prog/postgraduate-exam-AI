## 2. 审计方法

1. 解析 CSV 中 `parsed_content` 与 `parsed_options` JSON，提取题干和 A–D 选项。
2. 对 500 页图片型 PDF 进行中文/英文 OCR，并对疑似错配页使用不同版面模式进行第二次识别。
3. 对题干和选项分别做规范化匹配（忽略题号、空格、全半角括号及常见标点差异），识别“题干来自页面 X、选项来自页面 Y”的串题。
4. 对高风险结果再利用 PDF 页面图像和 CSV 中的清洁重复记录复核；只有能确定正确原题内容的记录才进入“确认不一致”。
