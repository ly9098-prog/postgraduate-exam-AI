按影响划分：

- **S1（严重，21 条）**：错题拼接、题干/选项语义错误、关键陈述或表图缺失，可能直接导致题目无法作答或答案发生变化。
- **S2（一般，6 条）**：字符、括号、变量下标/上标或短语残损，主要影响展示与检索，但仍应修正。

## 2. 审计方法与判定口径

1. 读取 CSV 的 `id`、`parsed_content.text`、`parsed_content.segments` 和 `parsed_options`；CSV 共 574 条。
2. 对 500 页扫描 PDF 逐页渲染并 OCR，按题干和选项进行规范化匹配；规范化仅忽略空格、换行、全角/半角标点等不改变语义的差异。
3. 对低相似度、题干与选项来源冲突、罗马数字陈述缺失、公式/表格结构异常等记录进行页面图像复核。
4. **PDF 原页作为本次审计的内容基准**；即使原书存在措辞或标点习惯问题，也不擅自按知识判断改写。
5. CSV 中若仅提供 `/static/question-assets/...` URL 而未同时上传图片文件，本报告只能核对元数据，不能验证图片像素内容；此类记录单列为“待资源核验”，不计入 27 条确认错误。
