4. **保留审计前快照**：修复前导出CSV或数据库备份，修复后再次执行逐字段比对。
5. **增加导入校验**：若题干含“如下表”“I.”“II.”等标志但解析结果缺少对应结构，应阻止入库并进入人工复核队列。

## 6. 审计口径与限制

- PDF为扫描图像型文档。OCR仅用于候选定位，报告中的错误记录已结合页面图像人工复核。
- 本报告核对的是**文字一致性**，不判断题目知识结论、标准答案或原书自身排版是否正确。
- 对PDF原样出现的内容按原文记录。例如第327页D项显示为`232B`，本审计不擅自改写原书。
- CSV中存在重复导入记录；内容完全一致的重复项未一律计入“文字不一致”，但建议后续单独进行主键去重和来源页唯一性审计。
