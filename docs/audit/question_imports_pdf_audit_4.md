# `question_imports` 题目数据与 PDF 原题一致性审计报告

## 1. 审计范围

- CSV 快照：`merged_question_imports.csv`
- 原题 PDF：`24王道操作系统选择做题本.pdf`
- CSV 记录数：574 条
- PDF 实际页数：500 页
- 审计字段：
  - `parsed_content`：题干文本、分段内容、代码/表格/示意图资源引用
  - `parsed_options`：选项标签与选项文字

> 说明：当前环境未连接实际数据库，本报告将上传的 CSV 视为 `question_imports` 表的当前导出快照进行审计。

## 2. 审计方法与判定口径

PDF 为扫描图像型文档。本次先对全书逐页 OCR，再按题干和选项进行相似度匹配；对低置信记录、重复导入记录、代码/表格/附图题和疑似跨页串题记录进行页面图像复核。

### 2.1 结构化题干的判定

部分记录的 `parsed_content.text` 中出现 `[代码区域见上图]`，但同时存在：

```json
{
  "render_mode": "segments",
  "segments": [
    {"type": "code_image", "url": "..."}
  ]
}
```

这类记录应按 `segments` 渲染，不能仅根据 `text` 中的占位文字判定代码或表格缺失。只有在资源引用错误、来源页错误、分段信息缺失，或没有任何结构化资源承载原题内容时，才计为不一致。

### 2.2 不计为实质错误的差异

- 题号、章节号、真题年份标签的有无；
- 不影响含义的空格、换行、全角/半角标点；
- PDF 原文中的明显错字被数据库编辑性修正；
- PDF 原文的选项标签排版错误被规范化为 A/B/C/D；
- JSON 对象键的插入顺序异常但“标签—选项文字”对应关系正确（单列为结构风险）。

## 3. 审计结论

### 3.1 已确认的实质不一致 ID

共确认 **6 个 ID** 存在题干内容、跨题拼接或结构化资源引用错误：

```text
269, 359, 392, 422, 495, 576
```

分类如下：

| 类型 | ID | 数量 |
|---|---|---:|
| 题干截断、残缺或错乱 | 269、359、392、576 | 4 |
| 题干与选项跨题拼接 | 422 | 1 |
| 代码图片资源引用错误 | 495 | 1 |

### 3.2 选项审计结论

上述 6 条记录的 **选项文字与各自 PDF 原题一致**，修复时不应改动选项。全表未发现可确认的实质性选项文字错配。

另有 3 条记录的选项 JSON 键顺序异常，但标签与文字对应正确：

```text
131, 132, 360
```

### 3.3 外部图片资源核验限制

CSV 中共有 12 条记录依赖外部 WebP 资源：

```text
192, 198, 199, 227, 228, 292, 482, 494, 495, 498, 500, 560
```

本次上传未包含 `/static/question-assets/` 下的实际 WebP 文件，因此不能对图片像素内容逐张校验。根据 `url`、`alt`、`source_page` 和对应 PDF 页面判断：

- 其中 11 条资源引用元数据与原题页面相符；
- ID 495 的资源 URL 与来源页明确指向了另一道题，确认错误。

除本报告列出的 6 条实质不一致外，其余记录在文本及结构化元数据层面未发现可确认的实质差异。

## 4.1 ID 269 — PDF 第 289 页

- **错误类型**：题干开头缺失、罗马序号错位
- **数据库当前内容**：

```text
页面大的好处是页表比较少
I.页面小的好处走可以减少由内碎片引起的内存浪费
III.影响磁盘访问时间的主要因素通常不是页面大小，所以使用时优先考虑较大的页面
```

- **问题说明**：
  - 缺少总问句；
  - 第 1 条缺少 `I.`；
  - 第 2 条被错误标为 `I.`，应为 `II.`；
  - 第 3 条序号正确。

- **PDF 正确内容**：

```text
在页式存储管理中选择页面的大小，需要考虑下列（ ）因素。
I. 页面大的好处是页表比较少
II. 页面小的好处走可以减少由内碎片引起的内存浪费
III. 影响磁盘访问时间的主要因素通常不是页面大小，所以使用时优先考虑较大的页面
```

> 注：PDF 原文第 II 条使用“好处走可以减少”，属于原书错字。本报告按原题呈现；业务侧也可编辑性修正为“好处是可以减少”。

- **选项**：一致，无需修改。
- **建议修复字段**：`parsed_content.text`
- **可参照的完整同源记录**：ID 268。

## 4.5 ID 495 — PDF 第 216—217 页

- **错误类型**：结构化代码图片引用错误
- **数据库当前结构化引用**：

```json
{
  "type": "code_image",
  "url": "/static/question-assets/code_region_216_peterson.webp",
  "alt": "加1和减1操作的指令序列",
  "source_page": 216,
  "region_type": "code"
}
```

- **错误说明**：
  - `code_region_216_peterson.webp` 是 ID 198/494 所用的 Peterson 互斥算法代码资源；
  - ID 495 原题需要的是“对 x 加 1 / 减 1”的机器指令序列；
  - 代码主体位于 PDF 第 217 页，当前 `source_page: 216` 也不准确。

- **PDF 正确代码内容**：

```text
// 加1操作
load  R1, x     // 取x到寄存器R1
inc   R1
store x, R1     // 将R1的内容存入x

// 减1操作
load  R2, x     // 取x到寄存器R2
dec   R2
store x, R2     // 将R2的内容存入x
```

随后为：

```text
两个操作完成后，x的值（ ）。
```

- **选项**：一致，无需修改。
- **建议修复字段**：
  - `parsed_content.segments[2].url`：改为专门的“加 1 / 减 1 指令序列”图片资源；
  - `parsed_content.segments[2].source_page`：改为 `217`；
  - 保留当前 `alt`，或改为更明确的“P1加1和P2减1的机器指令序列”。

## 5. 选项 JSON 键顺序风险

以下记录的选项标签与文字对应完全正确，不属于题目内容错误；但 JSON 对象的键插入顺序不是 A、B、C、D。若前端直接按对象插入顺序展示，会造成选项顺序异常。

| ID | 当前键顺序 | 建议顺序 | 内容是否一致 |
|---:|---|---|---|
| 131 | B, A, C, D | A, B, C, D | 一致 |
| 132 | B, A, D, C | A, B, C, D | 一致 |
| 360 | D, A, B, C | A, B, C, D | 一致 |

建议：数据库序列化和前端渲染均显式按 `A → B → C → D → E` 排序，不依赖 JSON 对象原始插入顺序。

## 8. 数据质量观察

1. **重复导入可直接用于回填**：ID 269、359、392、422、576 均存在同源完整记录，可避免重新 OCR。
2. **跨页边界切题风险**：ID 422 将第 454 页题干与第 453 页选项组合，建议导入流程增加“题干—选项语义一致性”和页边界检测。
3. **资源复用风险**：ID 495 的 `alt` 已更新为正确题意，但 URL 仍复用了上一题的 Peterson 代码图片，说明修改元数据时未同步替换资源路径。
4. **CSV 可移植性风险**：依赖 `/static/question-assets/` 的记录在脱离原系统后无法仅凭 CSV 完整还原原题。建议导出时附带资源包，或把代码/表格同步保存为结构化文本。
5. **主键不连续不等于题目缺失**：CSV 的 ID 存在空档，仅凭 ID 不连续不能判定 PDF 原题漏导入，故未列为本次内容错误。
