## Fix 1：题干残留原题号

### 问题

部分题目的 `content.text` 和 `content.segments[0].text` 中保留了 OCR 导入时的原题号前缀（如 `41.`、`14.`、`13.`），导致题干内容不干净。

### 根因

OCR 导入时，源文件中每道题前都有题号标记（如 `41.【2010统考真题】...`）。AI 标准化环节未一致地剥离该题号前缀，导致部分题目保留了原题号，部分没有。

### 影响范围

共 **169 题** 的 `content.text` 以数字开头，分两类：

| 类别 | 数量 | 示例 | 处理方式 |
|------|------|------|---------|
| 试卷类（`n.【年份统考真题】`） | 62 | `41.【2010统考真题】进程P0和进程P1...` | 剥离 `n.` 前缀，保留 `【】` 内容 |
| 普通类（`n.题目内容`） | 107 | `13.操作系统与用户通信接口通常不包括()` | 剥离 `n.` 前缀 |

### 修复目标

对每个命中题，执行：

1. `content.text`：删除开头的 `^(\d+)[.、．\s]` 前缀
2. `content.segments[0].text`（如果第一个 segment 是 `type=text`）：同步删除相同前缀
3. 保留 `question_imports.raw_text_preview` 不变（作为溯源依据）

### 用户确认项

- [x] 普通类题号（如 `13.操作系统...`）是否全部剥离 `13.` 前缀？回答：是
- [x] 剥离后是否影响前端知识点归类和检索？回答：不影响

## Fix 2：题目重复

### 问题

### 修复方案

**方案 A：保留旧题 + 去重新题（推荐）**
- 将新题 `is_active = false`，保留旧题
- 对旧题答案有明显问题的（如 id=33 乱码 `B、A、C、D`），用新题答案修正
- 对答案冲突组，需人工核实正确后标记

**方案 B：保留新题 + 删除旧题**
- 新题来自 `REIMPORT`，可能答案更准确
- 删除旧题涉及关联表（wrong_questions, practice_record 等），风险较高
