# 速记公式阅读与薄荷色主题

更新日期：2026-10-07。

## 范围与配色依据

- 修改范围为 `miniprogram/subpackages/formulas/` 的公式库、reader 和 formula-card。
- 色调以 `miniprogram/subpackages/study/practice/practice.wxss` 当前实现为准：页面背景
  `#F3FBF8`、主文字 `#23483C`、主操作 `#3A6F5B`、薄荷强调 `#7ED8B5`、
  轻选中背景 `#EAF9F4`、边框 `#D8EEE6`。
- 导航使用已实现的 `premium-nav` 的 `mint` variant；页面 JSON 的刷新/底部背景同时对齐。
- 不改练习页、全局 tokens、KaTeX vendor 和其他分包；警告、错误和标签的语义色保留。

## 阅读布局

1. 核心公式区去掉内部绿色底框和逐分组白色卡片，改为标题、公式列表和细分隔线。
2. 每条独立公式单独排列，每一显示行都有独立的原生横向 `scroll-view`。
   不缩小字号强行适配，不让长公式从不可到达的负偏移开始。
3. 复用既有 `splitFormulaGroup`；另外识别简单 `aligned` / `gathered` 外层内的独立等式。
   含嵌套环境、文本/子堆栈，或以等号、加减号开头的续行，不拆成独立公式。
4. 对复杂度大于 120、且只有一个安全顶层等号的普通公式，可在等号前分成两行。
   分式、根号和括号内不切分；矩阵、分段函数、既有结构化推导、链式等式和不明确的
   定界符保留原结构。常数、条件、绝对值与源公式内容保持不变。
5. 复杂度只用于分行和滑动提示的保守启发式，不是实际宽度测量。
   无论提示是否出现，每个公式显示行均可横向滚动。

## 展开阅读与手势

- 每个分组提供小号“放大查看”文字入口，不使用原生按钮默认尺寸；右上角使用关闭图标，
  交互热区保留 88rpx（375px 宽度设备上约 44px），视觉尺寸与触摸热区分离。
- 使用原生 `page-container` 展示内容自适应的底部面板，最大高度为当前窗口的 80%。
  展开前查询已有 reader 公式节点的宽高，按字号比例、标题、间距和安全区保守计算布局，
  一次 `setData` 同时提供公式节点、标题高度、面板高度与滚动区高度，再启动原生入场。
  不再使用 `afterenter` 修改分行和高度，避免“先打开、停一下、再展开”的二次布局。
- 完整公式节点在卡片准备时生成；单行公式直接复用已有节点，点击时不调用 KaTeX 重新解析。
  面板数据仅发送实际使用的节点，不携带另一套未使用的完整/分行树。
- 用已有公式显示片段的实际宽度（含字号换算及等号间距余量）决定是否复用安全分行。
  放得下时使用预先准备的完整公式，无法安全拆分时保持横向滚动。
  这种预计算不是放大面板最终 DOM 的精确测量；为避免动画中调整，间距采用保守余量。
- 按分组及窗口尺寸缓存排版，重复打开直接复用。内容改变时清空缓存，窗口尺寸或安全区
  改变时重新计算；关闭、换卡及组件卸载使未完成的测量回调失效。
- 仅超宽内容展示横滑说明。短内容保持紧凑，长内容达到上限后内部纵向滚动。
- 面板打开时，通过 `readingchange` 事件隐藏 reader 的切卡胶囊，避免遮挡公式。
- 复用 `formulastart` / `formulaend` 手势隔离；展开期间不将公式横滑当作切卡。
- 关闭不替换当前卡片、不重置 reader 滚动位置；原生 `afterleave` 与关闭图标共用幂等关闭。
- 卡片内容发生变化时关闭旧的阅读面板，避免保留上一张公式。

## 验证

新增独立 Node 回归入口：

```bash
cd miniprogram
node tests/test-formula-reader-layout.js
```

覆盖数学内容保留、独立公式分组、长等式分行、不安全结构回退、KaTeX 渲染、展开/关闭、
卡片变更关闭旧面板、展开前尺寸计算、单次更新、排版缓存、短/长内容高度适配和过期回调隔离，以及 mint 导航与背景配置。

2026-10-07 已在微信开发者工具模拟器查看基本积分公式（id=19）、根式积分展开面板、
公式库与练习设置页，并通过运行时调用确认根式积分有五条独立公式、关闭后仍保留原卡片
及 reader 的滚动目标。组件 WXML/WXSS 的局部编译通过。模拟器截图不等同于真机验收；
真机横滑、原生返回键、不同屏幕尺寸和 Android/iOS 字体表现仍需设备验证。

本轮自适应验证：模拟器中单条换元积分面板约 180px；两条指数函数公式面板约 253px，
公式均保留完整一行且不显示横滑说明；根式积分多条内容达到 675px 上限
（窗口高度的 80%）后纵向滚动。该数值仅是当前模拟器设备的测量结果，不是硬编码布局高度。

## 展开性能回归

2026-10-07 本轮模拟器采样中，两条指数公式首次打开在约 22ms 后提交唯一一次面板更新；
同分组重复打开命中缓存（0 次尺寸查询），根式积分首次打开也只有一次更新。
对每次打开记录 800ms 内的 `setData`，未发现入场后再修改节点或高度。
以上仅为这次模拟器采样，不代表真机延迟或动画总时长。当前短面板预计算高度约 261px，
长面板仍为 675px 上限；之前的 253px 是旧版入场后测量的结果。
