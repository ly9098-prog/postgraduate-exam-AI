# MVP 范围

> 原最小可行产品清单。2026-09-23 改掉「导入管线开发中 / OCR 仅代码就绪」的过时状态。
> 现行产品范围见 `docs/project/ROADMAP.md`，不要把本文件当成还在做的阶段计划。

---

## 核心功能（已完成）

- 微信登录 + 自动注册
- 题库管理（CRUD + 分页）
- 随机刷题 + 自动判分
- 错题本（自动收录 + 状态管理）
- AI 错题分析（模型由 Admin 配置；失败走降级缓存。错因分析以服务端核对过的作答事实为准）
- SM-2 间隔重复复习
- 题库导入（Excel/PDF/Word）
- 学习统计看板
- Docker Compose 部署

## 原「增强功能」

这三项都不再是「开发中」：

- AI 辅助导题：已实现。入库仍必须经过 `question_imports` 和人工确认。
- OCR 扫描版 PDF：导入管线已实现。全量 E2E 准确率验收未在本文件确认。
- 导入管线：文本标准化、切分、答案匹配和审核发布已经接在现行导入流程上，不再单独立项。

408 考试、知识地图、公式卡、番茄钟、导出见路线图，不属于这份 MVP 清单。

## 非 MVP

- 社区 / 论坛
- 多人协作
- 实时功能
- 拍照搜题
