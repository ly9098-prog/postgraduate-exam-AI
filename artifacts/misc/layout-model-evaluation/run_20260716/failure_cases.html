Failure Case Analysis — CDLA Layout Model

Analysis of CDLA layout model failures on 28 ds_sc.pdf pages

#1: Adjacency list undetected (Page 371)

Problem: CDLA returns only text+title regions. The adjacency list diagram (3 blocks of vertices and edges) is completely subsumed into the "text" region.

Root cause: The diagram is embedded within the text flow (between stem text and option text). CDLA treats it as part of the question text block.

Impact: Critical — if using CDLA directly, adjacency list diagrams would be entirely missing from content images.

Mitigation: Manual bbox override needed (which visual-v2 already has). A trained model with "diagram" class examples would solve this.

#2: B+ tree undetected (Page 380)

Problem: CDLA detects text+title+header but no figure. The B+ tree diagram is classified as "text".

Root cause: Similar to case #1 — B+ tree diagram positioned within text block, not visually separated enough for CDLA to distinguish.

Impact: Critical for any B+ tree / directed graph questions.

#3: CDLA figure bbox misalignment (Pages 369, 378, 379)

Problem: When CDLA does detect "figure", the bbox spans the full page width rather than tightly covering the diagram. E.g., p369: CDLA figure=[205,134,870,340] at 2x scale, which covers 665px wide — way wider than the actual BST diagrams.

Root cause: CDLA treats the entire right-half content column as one figure region rather than separating individual diagrams.

Impact: High — loose bbox results in content images that include unnecessary whitespace/neighboring text.

#4: Title vs header confusion (Pages 345, 400)

Problem: CDLA sometimes labels page header as "title" and sometimes as "header" inconsistently. E.g., p345 detects "header" while most pages detect "title". The page header (brand banner) and question number title are not consistently distinguished.

Impact: High — if building a rule on top of CDLA, the inconsistent labeling makes filtering unreliable.

#5: Equation label imprecision (Page 343, 412, 472)

Problem: CDLA detects "equation" labels but the bboxes are very small (~40x17px) and cover individual inline formula references rather than distinct formula blocks.

Impact: Medium — small inline formulas don't need separate content images, but CDLA doesn't distinguish inline vs display formulas.

#6: No stem/answer separation

Problem: Across all 28 pages, CDLA never separates question text from answer options. All text content is classified as a single "text" region.

Impact: Medium — visual-v2's OCR zone classification handles this, but a trained model could do it better.

Failure Distribution

  • Critical (diagram not detected): 25/28 pages (89.3%)
  • High (bbox misalignment / label inconsistency): 6/28 pages (21.4%)
  • Medium (imprecise labels): 28/28 pages (100%)

  • diagram detection: 28/28 vs 3/28 ✅
  • header exclusion: deterministic (y<28pt) vs 4/28 detected ❌
  • stem/answer separation: OCR zone classification vs not attempted ❌
  • blank ratio check: ✓ vs not applicable ❌
