Key Findings

1. PP-StructureV3 零样本效果

❌ figure 检出率仅 10.7%（3/28 页），不能替代 visual-v2

CDLA 模型将绝大多数 diagram 区域误分类为 text。对于考研数据结构的树、图、邻接表等特殊版面完全失效。

2. PubLayNet 效果

❌ figure 检出率 0%，完全不适用于中文试题版面

3. visual-v2 当前方案仍在可用状态

✅ 100% 覆盖 28 页的 diagram 检测（依赖手工配置 + 规则）

但人工审核率 96% 不可持续，每新增一个 PDF 需要大量手工调参。

4. 模型方案方向正确但需数据积累

⚠️ 建议并行推进：visual-v2 完成当前 apply，同时积累标注数据训练模型
