题干末尾混入页脚水印「【公众号:风中易小生】」。这些是 OCR 页脚噪声，正常应被 `text_normalizer` 水印表剥离，但 31 题未剥净（多为重建页路径 `reconstruct_pages.py` 产生）。

页码（id 随页）：`23, 36, 52, 68, 88, 103, 118, 141, 166, 174, 183, 194, 205, 224, 251, 306, 314, 339, 348, 355, 358, 370, 386, 402, 415, 428, 447, 469, 475, 483, 486`

- p52 id=640：`两个数 7E5H 和 4D3H 相加，得(\n)。[公众号:风中易小生]`

### 2.2 尾部残留答案线索罗马数字（4 题，high）

### 2.4 说明（非缺陷）
其余 C1 命中均为误报：题干尾数字串多为 C 语言代码/机器数（如 `si=-32767`、`[x]补=11110100`、`FFFFFFDFH`），「连续相似字符」多为合法罗马数字（III/IV）或十六进制（FFFF/0000）。**未发现页码引用、'P55' 之类残留**。

## 3. 检查 2：题干末尾缺失括号 ')'

- **237 题**题干以 `(` 或 `（` 结尾且括号未闭合。对照原页 OCR（如 p11 `…正确的是(`、p48 `…相同的是(`）确认：**这是本书「选择填空」的固定版式**——题干以开括号结尾，答案填在括号内，选项续写句子。故 237 题属正常版式，**非缺陷**。
- 其中 **约 81 页**（p11、p15、p19、p24、p33 等）原页在下一行有独立的 `)。` 或 `)` 行（OCR 将开、闭括号分开识别），导入时该 `)` 行被丢弃，故这些题干实际缺失闭括号。若要严格还原原页，可对这 81 题补 `)`；否则保留开括号也符合本书版式。**建议作为可选格式规范化，不列为错误。**
- 剩余 57 题括号不平衡但未以 `(` 结尾者，均为「题干在 `(` 后接 I/II/III 列表项」的同类版式（如 p16 id=603 `…分别是(\nI.机器语言…`），同样非缺陷。

1. **对照基准为同一 OCR 源**：`backend-ocr/remote/` 与 DB 数据同源于 PaddleOCR-VL，罗马数字字形（ⅡI/IⅢI）歧义大，故 6.3 项无法自动定稿，列为人工核对。
