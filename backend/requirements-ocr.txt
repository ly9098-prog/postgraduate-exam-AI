# 阶段八 OCR 可选依赖（扫描版 PDF 识别用）
#
# 这些包体积大（~500MB），且只有 OCR_ENABLED=true 时才需要。
# 主 requirements.txt 不包含它们，启动后端不依赖。
#
# 安装：
#   pip install -r requirements-ocr.txt
#
# 注意：
#   - paddlepaddle 在 Python 3.12 上需 >= 2.6.2
#   - 推荐在 Docker 容器或专用环境内安装
#   - 不装这些包时，扫描版 PDF 走 OCR 通道会跳过，文本型 PDF 不受影响
# PaddleOCR 升级记录:
#   2.7.3 → 2.10.0 (2024-12, latest 2.x, backward-compatible API)
#   - drop_score/det_db_thresh 等参数通过 **kwargs 透传，兼容性保持不变
#   - paddlepaddle 3.3.1 已安装，保持兼容
#   - 升级理由: PP-OCRv4 模型精度提升 ~5%, 更稳定的文本行检测
#   - 风险: 低 — API 签名完全一致
#
# WARNING: opencv-contrib-python 和 opencv-python 与 opencv-python-headless 冲突
# 故 paddleocr 用 --no-deps 安装，其依赖在此显式声明（替换 opencv 为 headless）
# paddleocr 本身需要单独用 --no-deps 安装（避免与 opencv-python-headless 冲突）
# 见 run.sh 中 OCR 安装逻辑
