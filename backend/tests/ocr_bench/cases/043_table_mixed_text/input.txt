1. 某系统有A、B、C三类资源，在T₀时刻系统状态如下表：
进程  Allocation  Need  Available
P0     A B C     A B C   A B C
       0 1 0     7 4 3   3 3 2
P1     2 0 0     1 2 2
P2     3 0 2     6 0 0
P3     2 1 1     0 1 1
P4     0 0 2     4 3 1
当前系统是否处于安全状态？
A. 安全
B. 不安全
C. 无法判断
D. 需要更多信息
答案：A

2. 某文件系统采用索引分配，索引块大小为1KB，每个指针占4B，
则文件最大为多少？
A. 256KB
B. 256KB + 64MB
C. 64MB + 16GB
D. 约16GB
答案：D

3. 一个32位虚拟地址系统，页面大小为4KB，页表项占4B，
则单级页表需要占用多少内存？
A. 1MB
B. 2MB
C. 4MB
D. 8MB
答案：C
