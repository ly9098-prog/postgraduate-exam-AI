1. 阅读下列C语言程序：
int main() {
  int a[5] = {1, 2, 3, 4, 5};
  int *p = (int *)(&a + 1);
  printf('%d', *(p - 1));
  return 0;
}
输出结果是什么？
A. 1
B. 5
C. 随机值
D. 编译错误
答案：B

2. 下列程序段的输出结果为：
int i;
for (i = 0; i < 10; i++) {
  if (i % 2 == 0) continue;
  printf('%d ', i);
}
A. 0 2 4 6 8
B. 1 3 5 7 9
C. 2 4 6 8 10
D. 1 2 3 4 5
答案：B
